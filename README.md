# Atena Studio

名簿（CSV）から、宛名ラベル・QR付き書類・名札などの個別書類をまとめて作成するツール。
1. QRコードの一括作成
2. 既存帳票（PDF）に対するQRコードのオーバーレイ
3. 帳票レイアウトの自由作成（開発中）

## 利用方法
### オンライン利用
本リポジトリにおけるPagesにアクセスする。
[こちらからツールにアクセス](https://kotakahashi-4u.github.io/qr-pdf-overlay/)

使い方・機能紹介ページは [about.html](about.html) を参照（アプリ内ヘッダーの「使い方・機能紹介」リンクからも開けます）。

### オフライン利用
1. 以下手順に従い、Zipファイルをダウンロードする。  
  <img width="960" height="540" alt="Image" src="https://github.com/user-attachments/assets/9fdb3c50-e2c3-4625-8e29-36b782e86baa" />

3. 解凍してできたディレクトリ内にindex.htmlがあるため、それをGoogle ChromeやEdge等のブラウザアプリで開く。

## 本リポジトリについて

本リポジトリは [kotakahashi-4u/qr-pdf-overlay](https://github.com/kotakahashi-4u/qr-pdf-overlay) をベースに、月ねこ(Tsukineko)が独自機能を追加したものです。オリジナル版の開発者に感謝します。

### 追加した機能（オリジナル版との差分）
- 検品用CSV出力（PDF生成と同時に、何ページ目にどのデータを埋め込んだかの対応表を出力）
- 生成URLへのUTMパラメータ自動付与
- QR配置座標のプリセット保存・呼び出し（ブラウザのlocalStorageに保存）
- ロゴ／角印画像の全ページ自動合成
- 既存PDFへのQR合成時に、背景PDFに元々埋め込まれていた画像を破壊しないよう修正
- 見た目を刷新。構造・タイポグラフィ・シャドウ言語はCal.com（getdesign製DESIGN.md参照）を土台にしつつ、配色は「月夜のインディゴ＋月あかりのゴールド」という月ねこ独自のブランドカラーに変更
- CSV入力フォーマットの見本ダウンロード機能（現在のテンプレート/帳票要素から必要な列を自動推定）
- 用途別テンプレート（計21種）— 代表的な4種（宛名ラベル／QR付き受講票／名札／カスタムで作る）はアイコン付きカードで直接選択、残りは「その他」カードからテンプレートページ（モーダル、カテゴリ別・ミニプレビュー付き）で選べる。QRコードは数ある帳票要素の一つという位置づけで、QRなしの用途にも対応
- マイテンプレート（新規帳票デザインモードで組んだ帳票レイアウトを名前を付けて保存・再利用。ブラウザのlocalStorageに保存され、①のテンプレートページにも表示される）
- 名簿のバージョン管理（ブラウザ内IndexedDBに保存。取り込むたびに前回との差分〈追加/変更/削除〉を表示、過去バージョンへの復元、JSONバックアップの書き出し/読み込み）。今後の拡張方針は[ROADMAP.md](ROADMAP.md)を参照
- 初回利用時に迷わないよう、ステップ番号をモード横断で統一し、上級者向け機能（名簿のバージョン管理／ロゴ合成・検品用CSV）を折りたたみ式に整理
- 用紙サイズをA4固定から可変に変更（A4/A3/B5/はがきを既存PDF合成モードでも選択可能に。以前は「新規帳票デザイン」モードにサイズ選択欄はあったが実際には反映されない見た目だけの項目だったため、実際に出力サイズへ反映されるよう修正）
- ロゴを刷新（インディゴ×ゴールドの2つの角丸スクエアが重なるインターロックマーク＋Quicksandフォントの「Atena Studio」ワードマーク。ヘッダーとfaviconに使用）
- 帳票要素の編集体験を改善。文字サイズはステッパー（−/＋）とよく使うサイズのプリセットボタンで直感的に変更可能に。拡大プレビュー上のテキスト要素はダブルクリックでその場編集（サイドパネルを行き来せず、プレビュー上で直接書き換えて即座に反映）
- 文字要素に書体（ゴシック／明朝／丸ゴシック）を設定可能に。拡大プレビュー上にも文字サイズ・書体の操作パネルを追加し、モーダルを閉じずに調整できるように。「書体の組み合わせ」プリセット（モダン／フォーマル／やわらか）で、帳票内の見出し・本文の書体をまとめて一括変更可能
- 拡大プレビューから既存のテンプレートページ（用途別ギャラリー）をモーダルを閉じずに呼び出し、レイアウトを選び直せるように
- 拡大プレビューでの要素ドラッグ移動時、ページ中央や他要素の端・中心に近づくと自動で吸着するスマートガイド（整列補助線）を追加。手作業での座標入力に頼らず、目視でバランスよく配置できるように
- 拡大プレビューの「サイズと座標」の数値入力欄は、通常はドラッグ操作で完結するため折りたたみ式（詳細設定）に変更
- 用途別テンプレート（計13種）＋案内状/チケットの帳票プリセットを全面デザイン刷新。アクセントカラーの帯・枠線・QRの案内キャプション・フッター等を加えて「白紙に毛が生えた程度」の見た目から脱却し、そのまま使える完成度に。案内状・送付状系は時候の挨拶（拝啓〜敬具）や記書きなど、実務でよくある定型文言をあらかじめ収録
- 配色（ブランドカラー）プリセットを追加。プリセットスウォッチまたはカスタムカラーを選ぶと、帳票内のアクセントバー・枠線・背景ティントをまとめて一括で塗り替え可能
- 文字要素の自動折り返しに対応（これまで長い文章は要素の枠を無視してはみ出して描画されていた不具合を修正。canvasプレビュー・PDF出力の両方に反映）
- 自社情報（会社名・サービス名・住所・電話・メール・インボイス登録番号・ロゴ画像）をブラウザに登録できる機能を追加。テンプレートを開くと自動で差し込まれ、「会社情報を挿入」ボタンでいつでも呼び出せる。テキスト要素には「自社情報との連携」欄を追加し、任意の要素を会社名・住所などに紐づけ可能
- 帳票要素に「ロゴ画像」タイプを新規追加（label/qr/table/boxに続く5種類目）。登録した自社ロゴを帳票内に自由配置でき、canvasプレビュー・PDF出力の両方に反映
- 配色プリセットを9色に拡充。ロゴ画像をアップロードすると代表色を自動抽出し、配色パレットの先頭候補として即座に使えるように
- 経理・取引書類のテンプレートを6種追加（見積書／発注書／納品書／受領書／請求書／領収書）。市販の帳票フォーマット（軽減税率対応）を参考に、右上ロゴ・宛先/自社情報の2カラムヘッダー・明細・小計/消費税(8%)/合計を再現。請求書には支払期限・振込先、受領書には受領確認文・受領日・受領印欄を収録。自社情報（ロゴ・会社名・住所・連絡先・インボイス登録番号）を登録しておけば選択時に自動で差し込まれる
- 「帳票要素の追加・編集」パネルを再構成。①要素を追加／②デザインを一括調整（自社情報挿入・書体の組み合わせ・配色をひとつにまとめて表示）／③差し込みタグ／④要素の詳細編集、の4ブロックに整理し、どこで何を追加・調整できるかを分かりやすく
- 差し込みタグの表示を改善。CSV読み込み前でも、選択中のテンプレートで使われているタグを自動抽出して表示するように（テンプレートを切り替えると連動して更新）
- 見本CSVのサンプル値を全19テンプレート分の実務的な内容に拡充。ギャラリーのミニプレビューと同じ辞書を共通利用
- 「表で直接入力・編集」機能を追加（CSVファイルを選ぶ方法とは別に、②の欄から選択可能）。選択中のテンプレートに合わせて列と見本データが自動で入った表が開き、セルの直接編集やExcel/スプレッドシートからのコピー＆貼り付けで名簿を作成できる。CSVアップロードは件数が多い場合向け、表入力は少数件やお試し用という住み分け
- 「名簿のバージョン管理」を②のカード内に統合し、独立したカードに見えないように整理。「一意キーとなる列（ID）」の説明も「一人ひとりを区別できる列（例: 会員番号・メールアドレスなど）」と具体例を添えて分かりやすく
- 「用紙サイズ＆帳票プリセット」から、案内状/チケットのプリセットボタンとマイテンプレートの選択・削除UIを撤去し、用紙サイズ設定のみのシンプルな構成に整理。プリセット2種は「重要なお知らせ」「汎用チケット」としてテンプレートギャラリーに統合（テンプレートの入口を①に一本化）。マイテンプレートの保存は④の末尾に移動し、読み込み・削除は①のギャラリーのマイテンプレートカードから行うように統一（削除ボタンをカードに追加）
- 「日本語フォント(TTF/OTF指定)」を④の「デザインを一括調整」内に移動し、「PDF出力用フォント（上級者向け・任意）」という説明を添えて、④の書体設定（見た目の切り替え）とは別の機能（PDF内の文字を画像でなく実データとして埋め込む機能）であることを明示
- 「配置プレビュー拡大・微調整」に元に戻す／やり直す（Ctrl/Cmd+Z・Shift+Z、画面上のボタン）を追加。要素の移動・リサイズ・文字編集・削除・複製・配色や書体の一括適用・自社情報の挿入・テンプレート選択など、帳票デザインへの変更を後から取り消せるように
- ダブルクリックで文字要素をその場編集しようとした際、クリックの微妙なズレで要素が意図せず動いてしまう不具合を修正（一定距離マウスが動くまではドラッグ移動を開始しないように変更）
- 選択中の要素をDeleteキーで削除、矢印キーで1mm移動（Shiftキー併用で10mm）、Ctrl/Cmd+Dで複製できるように。複製・削除はサイドパネルのボタンからも実行可能に
- ヘッダーを再設計。ロゴ・アプリ名・バッジを1つの塊にまとめ、「使い方・機能紹介」は右側へ移動。「QR画像一括出力」は使用頻度が低いため、対等な最上位タブから⋮メニュー内の項目に変更
- 「背景PDFに合成」モードに専用の①（背景PDFのアップロード）ステップを新設。従来は右カラム隅の小さいボタンに埋もれていて発見しづらかった
- 「背景PDFに合成」モードは、既存PDFの中身を解析せずQR/ロゴを機械的に重ねるだけで実用性が低いと判断し、無料版のUIからは撤去（初期表示モードは「新規帳票デザイン」に変更）。コード自体は削除せず、将来的に有料版機能（PDFの文字・レイアウトを解析して編集可能な帳票として自動生成する等）として復活させる前提で残してある
