# Atena Studio

名簿（CSV）から、宛名ラベル・QR付き書類・名札などの個別書類をまとめて作成するツール。
1. QRコードの一括作成
2. 既存帳票（PDF）に対するQRコードのオーバーレイ
3. 帳票レイアウトの自由作成（開発中）

## 利用方法
### オンライン利用
本リポジトリにおけるPagesにアクセスする。
[こちらからツールにアクセス](https://kotakahashi-4u.github.io/qr-pdf-overlay/)

使い方・機能紹介ページは [about.html](about.html) を参照（アプリ内ヘッダーの「使い方・機能紹介」リンクからも開けます）。

### オフライン利用
1. 以下手順に従い、Zipファイルをダウンロードする。

## 本リポジトリについて

本リポジトリは [kotakahashi-4u/qr-pdf-overlay](https://github.com/kotakahashi-4u/qr-pdf-overlay) をベースに、月ねこ(Tsukineko)が独自機能を追加したものです。オリジナル版の開発者に感謝します。

### 追加した機能（オリジナル版との差分）
- 検品用CSV出力（PDF生成と同時に、何ページ目にどのデータを埋め込んだかの対応表を出力）
- 生成URLへのUTMパラメータ自動付与
- QR配置座標のプリセット保存・呼び出し（ブラウザのlocalStorageに保存）
- ロゴ／角印画像の全ページ自動合成
- 既存PDFへのQR合成時に、背景PDFに元々埋め込まれていた画像を破壊しないよう修正
- 見た目を刷新。構造・タイポグラフィ・シャドウ言語はCal.com（getdesign製DESIGN.md参照）を土台にしつつ、配色は「月夜のインディゴ＋月あかりのゴールド」という月ねこ独自のブランドカラーに変更
- CSV入力フォーマットの見本ダウンロード機能（現在のテンプレート/帳票要素から必要な列を自動推定）
- 用途別テンプレート（計13種）— 代表的な4種（宛名ラベル／QR付き受講票／名札／カスタムで作る）はアイコン付きカードで直接選択、残り10種は「その他」カードからテンプレートページ（モーダル、カテゴリ別・ミニプレビュー付き）で選べる。QRコードは数ある帳票要素の一つという位置づけで、QRなしの用途にも対応
- マイテンプレート（新規帳票デザインモードで組んだ帳票レイアウトを名前を付けて保存・再利用。ブラウザのlocalStorageに保存され、①のテンプレートページにも表示される）
- 名簿のバージョン管理（ブラウザ内IndexedDBに保存。取り込むたびに前回との差分〈追加/変更/削除〉を表示、過去バージョンへの復元、JSONバックアップの書き出し/読み込み）。今後の拡張方針は[ROADMAP.md](ROADMAP.md)を参照
- 初回利用時に迷わないよう、ステップ番号をモード横断で統一し、上級者向け機能（名簿のバージョン管理／ロゴ合成・検品用CSV）を折りたたみ式に整理
- 用紙サイズをA4固定から可変に変更（A4/A3/B5/はがきを既存PDF合成モードでも選択可能に。以前は「新規帳票デザイン」モードにサイズ選択欄はあったが実際には反映されない見た目だけの項目だったため、実際に出力サイズへ反映されるよう修正）
- ロゴを刷新（インディゴ×ゴールドの2つの角丸スクエアが重なるインターロックマーク＋Quicksandフォントの「Atena Studio」ワードマーク。ヘッダーとfaviconに使用）
